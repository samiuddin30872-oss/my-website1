# Raja Refrigeration Website

## Setup
1. Open `supabase.js`.
2. Replace `PASTE_YOUR_PUBLISHABLE_KEY_HERE` with your Supabase publishable key.
3. Do not put a service_role/secret key in these files.
4. Deploy this folder to Netlify.
5. Customer page: index.html
6. Admin page: admin.html
